# Fine-tuning d’un modèle OCR

Bonjour,

Nous souhaitions partager avec vous un projet de **fine-tuning d’un modèle d’OCR** que nous menons en parallèle, dans une démarche didactique, afin d’approfondir nos connaissances et de développer nos compétences pratiques dans ce domaine.

Au cours de nos expérimentations, nous avons rencontré quelques difficultés avec le modèle fine-tuné, notamment :

- Des hallucinations, parfois importantes, avec du texte sans lien avec l’image.
- Des générations qui ne s’arrêtent pas correctement et se prolongent au-delà du contenu du document, parfois avec des répétitions.

Nous avons obtenu des **résultats encourageants sur certains documents**, avec des améliorations par rapport au modèle de base. La qualité reste toutefois variable selon les pages, et nous souhaitons mieux comprendre les régressions observées.

Nous aimerions beaucoup avoir votre retour sur ce projet, notamment vos observations et recommandations concernant les problèmes rencontrés, afin de mieux comprendre ces phénomènes et d’améliorer notre approche.

Le code d’entraînement, les configurations, les logs et les résultats d’expérimentation sont disponibles dans ce dépôt pour faciliter votre analyse. N’hésitez pas à nous faire savoir si vous avez besoin d’informations complémentaires.

Merci d’avance pour votre temps et vos précieux conseils !
